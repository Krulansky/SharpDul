* 플러그인

- Content Reel : 예시로 넣을 이름, 연락처 등 필요한 텍스트를 자동으로 채워줌

- Unsplash : 랜덤 이미지 삽입, 사진을 찾아줌

- Arrow Auto : 화면의 flow를 확인할 수 있도록 화살표를 그려줌

- Better Font Picker : 폰트가 어떤 모양을 하고 있는지 미리 볼수 있게 해줌

- Clean Document : 숨겨만 놓고 쓰지 않는 레이어 삭제, 하나의 레이어만 남겨진 그룹 해제, 여러 레이어 이름 한번에 재설정, 소수점 픽셀을 정수로 바꿈

- Super Tidy : 프레임들의 간격과 위치를 일정하게 정리해줌

- Product Planner : 원하는 템플릿에 프로젝트와 관련된 정보들을 표기 가능

- Feather Icons : 무료아이콘 제공

- iOS Browser UI Kit : iOS용 UI 키트 제공
