# SharpDul - Design Brief

**SharpDul** (short form **#Dul**) is a personal gamedev coach. It trains its owner mainly by
**re-studying their own projects** - games built from tutorials, with an instructor or with
AI - and grows with every finished project, like a skyscraper rising floor by floor on solid
foundations. The name plays on C#, on the owner's surname (Dulovic) and on *sharp* as the
opposite of *dull*. **SharpDul** is also planned as the studio name on the owner's game
licences (check the Slovak business register and EU trademarks before registering).

Status: design draft, 2026-10-25. Decisions below were made by the director in conversation;
open questions are listed at the end.

## Goals

1. **Remember what was built.** Spaced repetition over the lessons of real projects
   (LuaLander first), so knowledge does not fade after a project ends.
2. **Learn C# in depth.** The app itself is written in C#; building SharpDul is C# training too.
3. **See code affect gameplay.** Change a value or a line, watch the mechanic change live.
4. **Play with the tools that come naturally** - particle effects first - and practise UI.
5. **No pressure.** Daily or in bursts, never deadline-driven.

## Platforms

The director has an iPhone and Windows PCs (school + home), **no Mac**. A native iOS build
(Unity or .NET MAUI) requires a Mac with Xcode, so:

| Part | Platform | Tech | Contents |
|------|----------|------|----------|
| **SharpDul Pocket** | iPhone (and any browser) | Blazor WebAssembly **PWA**, C# | Quizzes, tests, spaced repetition, XP, Code Lab, small Mechanics Lab |
| **SharpDul Playground** | Windows PC | Unity `6000.3.14f1` project | Particle Lab, UI Lab, 3D models and animation, bigger mechanics |

- A PWA is installed from Safari via *Share > Add to Home Screen*; it runs full-screen and
  offline. No App Store and no Apple fee.
- Hosting: GitHub Pages (free for a public repo).
- **Hypothesis to test early:** Unity 6 supports mobile browsers, so a small Particle Lab
  built as Unity WebGL might run inside Pocket on the iPhone. Prototype before relying on it.
- 3D models from Blender export as `.glb` (glTF) - usable both in Unity and on the web.
  Animation work waits for game 3 (the 3D game).

## Content

- **Source:** each project's scripts and docs (`GAMEDEVNOTES.md`, `KnowledgeHandover.md`,
  `PROJECT_STATE.md` lessons), extended by AI with wider Unity/C# knowledge and combinations
  across projects.
- **Generated by the agent during work sessions**, reviewed, and committed as JSON
  **content packs** (one per project or topic). The app holds no API key and costs nothing
  to run. Every question links back to the file and lines it came from.
- **Start:** LuaLander pack (e.g. `Lander.cs`: states, events, `AddForce`/`AddTorque`,
  `Time.deltaTime`, singletons, `LanderVisuals` listener pattern).

## Question types by level

| Level | Types |
|-------|-------|
| **Easy** | Multiple choice; "What does this code do?"; true/false |
| **Medium** | + Fill in the missing line; spot the bug |
| **Hard** | + Write the function; explain the trade-off; cross-project questions |

Fill-in, find-the-bug and write-from-scratch stay out of Easy.

## Repetition

- Spaced repetition decides what comes back and when. v1 uses **Leitner boxes**
  (simple, and boxes map visually to mastery); the algorithm can be swapped later.
- Two modes: **Daily** (short session of due cards) and **Burst** (drill one project or
  topic, e.g. before starting a new game).

## Progression (gamification)

- **XP and levels** for answered and mastered cards.
- **Active days**, not a breakable streak: "active 4 of the last 7 days". Missing a day never
  resets anything.
- Mastery per project = the "floors" of the skyscraper.

## Labs

- **Mechanics Lab** (Pocket, starts with LuaLander): a small lander simulation in C# with
  sliders bound to the real values from `Lander.cs` (`force = 700f`, `turnSpeed = 100f`,
  `GRAVITY_NORMAL = 0.7f`, `fuelAmountMax = 10f`). The matching code line is shown and
  highlighted while you drag.
- **Code Lab** (Pocket): read and edit C# snippets inside quizzes.
- **Particle Lab** (Playground, maybe Pocket): free **sandbox** with saveable presets, and
  **challenges** ("recreate this effect").
- **UI Lab** (Playground): "build this screen" exercises in uGUI / UI Toolkit.
- **Minigames** in C#, later.

## Look and feel

Inspired by *Learn Unity In 30 Days* (App Store): bold playful headline font, warm colours,
big card buttons, saved/favourite lessons, offline. Unlike it: content grows with the
owner's own projects instead of a fixed 30-day course, and **no tracking**.

## Users

The owner first; possibly shared with classmates later.

## Decided

- **Languages:** EN, SK and KR (Korean), switchable in the app. Gamedev terms stay English
  everywhere.

- **Backup:** browser storage on iPhone can be lost (e.g. clearing Safari data), so the app
  has **Export** and **Import** buttons that save/load all progress as one JSON file
  (Files / iCloud Drive). No login, no server.
- Repo `github.com/Krulansky/SharpDul` is **public**, so GitHub Pages hosting is free.

- Visual identity (logo, colours, font) is designed **by the director**, after the first
  prototype. The prototype uses neutral placeholders.
